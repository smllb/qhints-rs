# qhints-rs

qhints-rs scans UI elements on your screen, assigns each one a keyboard label (a "hint"), and lets you
interact with them by typing — no mouse required.

Type a label → click. Hold Ctrl → hover. Press `/` → select text. Press Shift → drag.

![screenshot](https://i.imgur.com/Wibnmd4.jpeg)

- **X11 only** (Wayland not yet supported)
- Rust rewrite of [qhints](https://github.com/smllb/qhints)
- ~3200 lines of Rust
- Daily-driven on i3wm with picom
